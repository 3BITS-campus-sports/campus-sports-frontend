# Campus Sports Booking – Frontend (Mobile SPA)
**Echipa 3BITS** | Disciplina: Ingineria Programelor (Laborator 6)

Acest repository conține aplicația client Single Page Application (SPA), optimizată Mobile-First, conform prototipului proiectat în Figma.

---

## 🛠️ Stack Tehnic & Coding Style
- **Framework UI:** React.js 18 (SPA)
- **Build Tool:** Vite
- **Stilizare:** CSS3 / Tailwind design tokens (conform tematicii Figma)
- **Coding Style:** [Google JavaScript Style Guide](https://google.github.io/styleguide/jsguide.html)

---

## ✨ Funcționalități Inițiale (Laborator 6 - MVP)
- Explorarea catalogului de facilități sportive (bazin, fotbal, fitness, baschet).
- Comutare dinamică de monedă RON / EUR (suport studenți Erasmus).
- Calcul automat al tarifelor diferențiate (Student -50%, Profesor -30%, Amator).
- Formular de rezervare slot orar și opțiune de închiriere echipament.
- Emiterea biletului electronic securizat cu Cod QR după confirmare.
- Comutare Temă Luminoasă / Întunecată (Dark Mode).

---

## 🚀 Rulare Locală
1. Instalare dependențe:
   ```bash
   npm install
   ```
2. Pornire server de dezvoltare:
   ```bash
   npm run dev
   ```
3. Deschide în browser: `http://localhost:3000`
